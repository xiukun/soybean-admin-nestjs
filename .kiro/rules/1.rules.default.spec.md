# backend项目遵循规范：
1. 我们在开发阶段直接调整SQL和seed数据，不需要创建迁移文件，确保本地与docker中的数据一致性（deploy和prisma）。
2. 目录使用 kebab-case 命名
3. TypeScript 类型安全
4. AMIS低码后端接口标准返回格式：
   - status: 返回 0，表示当前接口正确返回，否则按错误请求处理
   - msg: 返回接口处理信息，主要用于表单提交或请求失败时的 toast 显示
   - data: 必须返回一个具有 key-value 结构的对象
   - status、msg 和 data 字段为接口返回的必要字段
5. 分页表格返回格式：
   ```json
   {
     "status": 0,
     "msg": "",
     "data": {
       "options": [],
       "pageNum": 1,
       "pageSize": 10,
       "total": 2000
     }
   }
   ```
6. 禁止直接返回字符串或数组，必须使用 key 包装
7. AMIS分页参数规范：
   - 前端请求参数：使用 page 和 perPage
   - 后端返回格式：使用 pageNum 和 pageSize
   - 示例请求：?page=1&perPage=10
   - 示例响应：{ "data": { "pageNum": 1, "pageSize": 10, "total": 2000, "options": [] } }
