## 新增需求

### 需求：按钮权限控制
系统 SHALL 支持按钮级权限管理，按钮以全局唯一 `buttonCode` 标识，可关联菜单或作为全局按钮，适配多数据库；授权基于角色分配按钮，前端与低代码均据此控制显隐与操作。

#### 场景：按菜单类型维护按钮资源（menu/lowcode）
- **WHEN** 管理端在“菜单管理”中选择某条菜单（menu）或低代码页面（lowcode）打开“按钮管理”抽屉
- **THEN** 系统返回该菜单下的按钮列表（可为空），并允许对该菜单的按钮执行增删改查（CRUD）

#### 场景：按钮资源全局唯一约束
- **WHEN** 管理端创建按钮时提交的 `buttonCode` 与现有任意按钮重复
- **THEN** 后端拒绝并返回明确错误信息，前端展示“buttonCode 已存在”

#### 场景：防锁死（权限配置入口默认可见）
- **WHEN** 当前用户尚未配置任何按钮权限（或按钮下发失败）
- **THEN** “按钮管理/创建按钮”等用于配置权限的入口仍应可见，以保证可以完成初始配置

#### 场景：按菜单加载按钮列表
- **WHEN** 前端/设计器以菜单 ID 调用按钮查询接口（含 `findVueMenuBtn` 兼容）
- **THEN** 后端返回 `status: 0`，`data.options` 为按钮数组（含 buttonCode/buttonName/menuId/type/orderIndex），空数据返回空数组且不报错。

#### 场景：角色分配按钮权限
- **WHEN** 管理端在角色管理为角色选择/取消按钮列表提交保存
- **THEN** 系统持久化角色-按钮关系并更新授权策略，下次鉴权/登录下发该角色可用按钮集合。

#### 场景：按钮权限校验与拦截
- **WHEN** 用户触发受控按钮操作但其按钮权限缺失
- **THEN** 后端返回 403（含 msg 提示），前端应隐藏或禁用该按钮并展示无权提示；已授权则正常执行。

#### 场景：低代码设计器权限过滤
- **WHEN** 低代码设计器加载页面或执行保存/插件操作
- **THEN** 根据当前用户按钮权限过滤可执行操作；无权操作需阻断并提示，同时按钮列表与菜单树保持同步。

#### 场景：设计器绑定按钮权限（运行时使用 buttonCode 判断）
- **WHEN** 设计器在组件属性面板选择“绑定权限”，选择一个按钮权限（值为 buttonCode）
- **THEN** 设计器在 schema 中写入 `hiddenOn: ${getPermissionById('<buttonCode>')}`（保留函数名 getPermissionById）
- **AND** Vue 运行时根据 `GET /authorization/getUserButtons` 下发的 buttonCodes 判断是否隐藏
